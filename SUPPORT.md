# Support

## Getting Help

- **Questions and problems:** open an
  [issue](https://github.com/simbo-actions/actions/issues/new/choose) in this
  repository. The action repositories have issues disabled; everything is
  handled here.
- **Vulnerabilities:** do not open an issue; see [SECURITY.md](SECURITY.md).
- **Ideas and contributions:** see [CONTRIBUTING.md](CONTRIBUTING.md).

Before opening an issue, please check the README of the action and the existing
issues.

## Support Policy

These actions are maintained by one person in their spare time. There are no
guaranteed response times; reports are handled on a best-effort basis.

- **Supported versions:** the latest major version of each published action.
  Older major versions receive no fixes.
- **Fixes** are released as patch versions, **features** as minor versions.
- **Breaking changes** come only in major versions and are described in the
  changelog. Deprecations are announced in a minor version before the removal.
- **Runtime:** actions follow the Node.js runtime of GitHub Actions. When GitHub
  deprecates a runtime, the actions move to the next one in a major version.

## Changelogs and Releases

Every action has its own changelog and GitHub releases in its repository, for
example
[`simbo-actions/signed-commit/releases`](https://github.com/simbo-actions/signed-commit/releases).
The [organization profile](https://github.com/simbo-actions) lists all actions.
