# Security Policy

Please report vulnerabilities in any action of `simbo-actions` **privately** via
[private vulnerability reporting of the monorepo](https://github.com/simbo-actions/actions/security/advisories/new),
not in public issues.

Supported versions, security practices, and how to verify a release are
described in the
[security policy of the monorepo](https://github.com/simbo-actions/actions/blob/main/SECURITY.md).
