# Contributing

All actions of `simbo-actions` are developed in the monorepo
[`simbo-actions/actions`](https://github.com/simbo-actions/actions). The action
repositories contain build artifacts only and accept no issues or pull requests.

Please read the
[contribution guidelines](https://github.com/simbo-actions/actions/blob/main/CONTRIBUTING.md)
of the monorepo and open issues and pull requests there.
